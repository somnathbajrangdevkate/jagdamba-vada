# Jagdamba Vada — Cinematic 3D Website

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Main files
- `src/App.tsx` — page sections, copy, product data, WhatsApp enquiry links
- `src/components/VadaScene.tsx` — procedural 3D vada scene (React Three Fiber)
- `src/styles.css` — visual design and responsive layouts
